allocation suggestions. Investment profit/risk preference is therefore not gold truth.

natural compactions. A completed user turn is not proof of workflow completion.

These scripts test local frozen-source cognition, not Google/provider reliability,
natural human Goal change, autonomous trading or realized investment returns.
