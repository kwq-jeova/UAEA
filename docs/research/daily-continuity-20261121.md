# N1X Daily 工程进展（2026-11-21）

Daily 使用受 Guard 保护的 Bolt 和 Harness 0.170，单并发、64K Context、1 GiB KV。Host 维护授权、来源和非权威 Goal 候选；Harness 负责工具循环和压缩。单轮联网授权与当前窗口的持续授权分别处理。Host 回执、实际送入下一请求的正文与最终回答分开核对。

最后一次普通请求保留已有工具目录和回执，使用只作答模式；Host 拒绝新增执行。若最后一个名额用于原生压缩，则记录缺少普通作答机会。阶段性正文可供新进程核验恢复。主批和充分证据侧批共 5 个真实窗口、20 份 Bolt 请求、14 次新工具操作，含被拒绝的提案。75 项 Daily CPU 回归通过。受控五页材料交出签收号和出处；八页材料依旧出现裸工具调用文字，整项未完成。恢复后的站务任务报对日期和水位，但出现额外确认。摘要失真、语义完成度与长期用户收益仍需独立评价。

[Daily 源码检查点](checkpoints/daily-n1x-20261121.zip) 保存 N1X Daily 安装目录顶层的第一方 Python 源码、测试、运行计划、Goal 工具定义和当时的使用说明。入口为 pilot.py。该快照用于比对既有 N1X 部署，依赖机器上已有的历史研究驱动、受保护模型服务、终端编辑依赖及 Harness 可执行文件。主仓库的 Harness 和出站视图适配可直接用 Git 查看差异。

原始 Native、HTTP/SSE、用户 profile、Journal 和 Guard 采样按本地归档管理。独立核查批次为 UAEA_DOCS 下的 20261121_DailyWebFinal 和 20261121_ContextExecutionContinuity；后者的「复核入口.md」给出逐轮核查方法。本次源码同步不改变研究评级。
