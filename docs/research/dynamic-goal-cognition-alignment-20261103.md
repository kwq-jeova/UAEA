## 2. 三方共同目标与需澄清的假设

**VISION**：从长期交互和真实观察中理解用户当前方向，并结合条件、资源、约束及新证据，
发现值得用户考虑的发展方向。最终产物应是有依据、有实际价值且允许“不建议”的条件性建议；
不是预测下一句话、给用户固定分类标签，也不是推测隐藏心理动机。

**HYPOTHESIS**：Goal可能跨短期话题保持稳定，也可能局部修订、反复试错或显著转变。
短时行为不能单独证明长期方向改变；长期稳定也不能证明成功、最优或正确。
相同的稳定行为可能来自收敛、条件瓶颈、路径惯性或缺少观察；这些解释可能在现有记录中不可区分。
不能把“稳定”预先定义为认知质量指标，也不能用抗变化阈值阻止用户明确修订。

必须区分三件事：用户实际目标的变化、可观察的用户目标声明变化、UAEA对目标解释的不确定性变化。
后两者可在限定实验中观察，第一件事通常是潜在变量，不能仅由模型输出获得真值。
当前明确任务、推断的长期Goal、可行行动路线和正式ActiveGoal也不是同一对象。

**DESIGN INTENT**：保留[Zero State的三个语义](information-theory-lineage-20261102.md#221-goal-zero-state三个独立语义)：
No ActiveGoal、No Goal Hypothesis、实验Null Goal Model不能互换。
Null对照不取消当前任务、用户约束、安全要求或授权检查；自由对话也允许不存在值得保留的长期Goal。

**VISION / UNKNOWN**：未来可主动提出一个有预期收益的实验或方向，但目前没有已校准的收益概率或效用函数。
“70%”只是示例；建议不等于采纳Goal，采纳也不等于获得执行权限。

## 4. Shannon基础与独立架构判断

**DESIGN INTENT**：Shannon信息论约束未来的信息、不确定性及更新测量。
对定义好的离散变量X及分布p，`H_p(X)=-Σ_x p(x)log₂p(x)`；
单个结果的surprisal为 `-log₂p(x)`。数值属于所选变量和概率模型，不是文本固有的“有效bit”。
连续变量还需另说明测度及离散化等前提。本轮不估计分布、不计算bit。
[Shannon原文](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)

**UNKNOWN**：自然交互中Goal的候选空间、生成过程、有效样本量、概率校准和语义真值尚未定义。
Token数、模型自评、重复频次、词面相似或候选集合大小都不能直接冒充熵。
允许先做可识别性与反例实验，再决定是否值得拟合统计模型；这不等于已建立信息论Goal模型。

| 工具候选 | 有价值之处与前提 | 当前判断 |
| --- | --- | --- |
| MDL / Prequential MDL | 比较明确编码或概率模型对同一观察序列的压缩/预测，并支付模型复杂度；窗口、编码与在线可用信息必须固定 | HYPOTHESIS；先定义观察和可否定目标，避免“更短的Goal描述”被当作更真实或更重要 |
| Bayesian latent state / Change Point | 明确似然、转移/变点先验及观测策略后表达不确定性 | HYPOTHESIS；参数变化不自动等于用户Goal变化，现有短轨迹不足以识别二者 |
| Information Bottleneck / Rate-Distortion | 需定义保留对象、相关目标、失真与分布 | 暂缓；没有语义失真标准时，压缩率不是认知质量 |
| VOI / 决策理论 | 依赖行动结果、概率、效用、成本和风险；新信息有用不等于应立即执行 | 作为长期方向；当前只能在明确限定的小案例中评价可行性或案例定义的收益，不能声称真实预期价值 |
| 集合式候选解释与条件可行性对照 | 可以不虚构概率，先暴露无法识别的解释和约束变化 | 建议下一步的离线基线；不是新Runtime状态结构或Goal算法 |

理论依据：[Grünwald MDL教程](https://arxiv.org/abs/math/0406077)；
[Adams/MacKay变点模型](https://arxiv.org/abs/0710.3742)；
[Berkeley VPI教材](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/vpi.html)。
这些资料提供数学工具，不证明UAEA的潜在Goal具有某种分布或结构。

**CONFLICT**：用累计bit、模型confidence、摘要重复或预设70%直接采纳Goal、覆盖用户修订或放行执行。
**UNKNOWN**：仅靠Shannon理论无法确定人的目标含义和建议价值；需要独立的语义观察、评价目标及偏好/效用依据。

局部认知错误可以被研究、暂时保留及修正；不因此取得正式Goal、权限、执行事实或Memory权威。
