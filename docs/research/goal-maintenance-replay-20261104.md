## 1. 研究问题与独立判断

给定相同、已经由研究者解释的输入：
- 每次从全部保留历史重放；
- 保留上一非权威视图，仅处理新记录；旧解释发生变化时失效并重建；
二者能否一致，省下什么工作，旧错误怎样保留或纠正？

**VERIFIED（本轮）**：增量复用减少了重复ingest；简单历史缓存获得相同收益，未显示Goal特有优势。
**VERIFIED（合成干预）**：只更新新输入、不处理旧解释撤回，能保留错误依据；
依赖变化后重建可恢复与全重放一致。
**UNKNOWN**：谁能可靠判断语义解释错误、自然Goal形成、模型调用成本及建议现实价值。
同一错误但登记合法的语义判断在撤回前仍会使两个主方法都错，不能说缓存解决了幻觉。

本轮新增的是隔离实验调度、计量和通用失效处理，不是新的Goal语义算法或生产契约。

每个时点只向处理器提供此时可用的原始记录/语义判断；未来操作不进入处理器。

两种主方法可访问相同来源，均允许显式用户修订，也均可纠正先前解释。
以完整core、建议选项及来源比较，不仅比较一个direction标签。

数据与协议在首次运行前冻结，gold只用于评价。单个Coding AI设计/审核，不是独立语义盲评。
没有为了提高结果改动原始gold、旧实验或现有语义处理器。

## 5. 撤回干预：旧解释必须能失效

这是**在S-A合成序列上的新合成干预**，独立于普通结果，不冒充新的自然用户修订。

- 时点1–2：将原“口述史”解释故意登记成“自行车”，原用户quote和原文仍正确且不变。
- 时点3：研究者撤回错误解释，恢复基于旧u1的正确解释。新的审查依据只从时点3可用，不提前泄露。
- 时点7：沿用原序列真实的合成用户显式改向，才产生heritage→bicycle_access修订记录。

结果：
- 两个主方法在时点1–2都接受错误语义输入。来源/登记合法不能证明解释正确。
- 主增量方法在时点3发现旧u1的解释版本改变，重放当前3条前缀；
  与按需全重放一致恢复heritage，不凭认识纠正制造“用户取消了自行车”的历史。
- 原错误视图仍按当时cut与review-set hash保留，不以新认识覆盖旧审计。
- 时点7才根据u7保留合法改向和旧方向历史。
- 不检查依赖变化的诊断缓存，在时点3–9全部与完整正确状态不同。

**值得注意**：时点7–9诊断缓存的direction标签碰巧也为bicycle_access，
但仍依据早期错误u1，缺少合法修订历史和正确来源。
只查标签会把这种情况误计通过；本轮完整状态/来源比较能暴露它。

| 每种表示的9时点撤回干预 | 全历史重放 | 主增量（必要时重放） | 诊断缓存 |
| --- | ---: | ---: | ---: |
| ingest次数 | 45 | 11 | 9 |
| 旧解释撤回时重建 | 每时点均重放 | 时点3重放 | 不处理 |
| 与全重放完整结果一致 | 参照 | 9/9 | 仅时点1–2 |
| 纠正前语义仍错误 | 是 | 是 | 是 |

多处理2条旧记录是失效修复的明确成本，不声称维护永远无成本。
撤回判断来自预定义研究语义，不是Runtime自动发现错误，也不是正式Host Goal控制。
如果没有外部正确纠正，两个主方法可以持续保留错误，不能据此报告抗幻觉全PASS。

## 7. 独立结论

| 维度 | 判定 |
| --- | --- |
| 给定语义下的状态/选项一致性 | PASS（主方法限定） |
| 已知依赖撤回后的恢复 | PASS（合成干预，保守重放） |
| 认知语义正确性 | PARTIAL/有明确局限：纠正前两组均错 |

| 额外Goal表示收益 | 未显示；通用历史缓存有同等复用收益 |
| 模型Token/真实建议净价值 | UNKNOWN |
| 正式Runtime准入 | 未测试，不建议直接接线 |

**现在有证据支持的最小认识**：
已有信息的复用可以省重复处理，但必须能因来源/解释变化而失效；
这一点不需要新Goal Engine。复杂候选表示没有在本组任务上胜过简单历史。

不应把下一阶段投入继续放在更多缓存或性能优化。
真正未解决的是：如何获得可质疑、可撤回的语义判断，以及何时有依据保留或纠正它，
同时不制造虚假的用户Goal历史。来源hash只能验证引用版本，不能完成语义判断。
后续若开展模型实验，应先固定少量“旧解释被质疑→新依据→当前候选纠正”的任务及独立评价，
不围绕Bolt特定字段/Prompt反复求PASS，也不让纠错机制接管正式Goal Adoption。

现实条件性建议的价值仍需独立任务结果。当前实验不支持新增认知权威或自动Goal Evolution。
若未来简单历史已足够，接受它；若无法获得可靠语义依据，应保持UNKNOWN，不能以缓存稳定替代正确性。
